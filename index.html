    Лабораторная работа 1: Работа с сокетами¶

    Обзор¶

    Данный проект представляет собой практическую реализацию пяти заданий по работе с сокетами в Python. Все задания выполнены с использованием стандартной библиотеки Python.

    Цели работы¶

    • Изучение основ сетевого программирования
    • Практическое применение библиотеки socket
    • Реализация клиент-серверной архитектуры
    • Работа с различными протоколами (UDP, TCP, HTTP)
    • Освоение многопоточного программирования

    Технические требования¶

    • Python 3.8+
    • Библиотеки: socket, threading, json, math, urllib.parse
    • Протоколы: UDP, TCP, HTTP

    Структура заданий¶

    Номер Протокол Описание
    Задание 1 UDP Простой обмен сообщениями
    Задание 2 TCP Математические вычисления
    Задание 3 HTTP Веб-сервер с HTML
    Задание 4 TCP Многопользовательский чат
    Задание 5 HTTP Веб-приложение с формами

    Запуск программ¶

    Главное меню¶

    python main.py

    Отдельные задания¶

    # Задание 1 - UDP Hello
python task1_udp_hello.py [server|client|demo]

# Задание 2 - TCP математические операции
python task2_tcp_math.py [server|client|demo]

# Задание 3 - HTTP сервер
python task3_http_server.py [server|client|demo]

# Задание 4 - Многопользовательский чат
python task4_chat.py [server|client|demo]

# Задание 5 - Веб-сервер для оценок
python task5_web_server.py

    Архитектура проекта¶

    Файловая структура¶

    .
├── main.py                 # Главное меню приложения
├── task1_udp_hello.py     # Задание 1: UDP Hello
├── task2_tcp_math.py      # Задание 2: TCP математика
├── task3_http_server.py   # Задание 3: HTTP сервер
├── task4_chat.py          # Задание 4: Чат
├── task5_web_server.py    # Задание 5: Веб-сервер
├── index.html             # HTML страница для задания 3
└── docs/                  # Документация
    ├── index.md           # Главная страница
    ├── tasks/             # Описание заданий
    └── conclusion.md      # Заключение

    Архитектурные решения¶

    • Модульная структура - каждое задание в отдельном файле
    • Единообразный интерфейс запуска (server/client/demo)
    • Обработка ошибок и исключений
    • Детальное логирование процессов

    Результаты выполнения¶

    Реализованные функции¶

    • UDP клиент-сервер с обменом сообщениями
    • TCP сервер для математических вычислений
    • HTTP сервер с поддержкой GET запросов
    • Многопользовательский чат с поддержкой threading
    • Веб-приложение для работы с оценками (GET/POST)

    Статистика проекта¶

    • Общий объем кода: около 800 строк
    • Количество файлов: 6 Python модулей
    • Поддерживаемые протоколы: UDP, TCP, HTTP
    • Математические операции: 4 типа

    Образовательная ценность¶

    Изученные концепции¶

    • Основы сетевого программирования
    • Различия между UDP и TCP протоколами
    • Структура HTTP запросов и ответов
    • Многопоточное программирование
    • Архитектура клиент-сервер

    Практические навыки¶

    • Создание сетевых соединений
    • Обработка данных в различных форматах
    • Работа с потоками (threading)
    • Разработка простых веб-приложений
    • Отладка сетевых приложений

    Дополнительные материалы¶

    • Документация Python socket
    • Руководство по threading
    • HTTP/1.1 спецификация
